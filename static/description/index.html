🔒 100% Self-Hosted — No External Services Needed

Unlike other signature modules that depend on iLoveSign, DocuSign, or HelloSign, Easy Sign runs entirely inside your Odoo instance. Your documents never leave your server. No API keys, no monthly fees, no data sharing.

How It Works

Simple 4-step signing workflow

1

Upload Document

Upload a PDF, add signers' names and emails, set optional expiry date and invitation message.

2

Send Invitations

Click "Send for Signature" — Odoo emails each signer a secure, unique signing link instantly.

3

Signer Reviews & Signs

Signer opens the link, reviews the PDF, draws their signature on canvas, and clicks Sign.

4

Signed PDF Ready

Once all parties sign, the PDF with embedded signatures is saved in Odoo and requester is notified.

🌐 Arabic & English — Instant Language Switch

The public signing page includes a language toggle button.
Switching to Arabic automatically applies RTL layout, Cairo font,
and flips the two-column layout — PDF on the right, signature on the left.

📦 Technical Requirements

  • Odoo 18 Community or Enterprise
  • Python packages: reportlab, Pillow, pypdf / PyPDF2
  • Depends on: mail, web
  • No external API keys required
  • Outgoing email configured (SMTP)
  • Works on all major browsers (Chrome, Firefox, Safari, Edge)
